## 使用边界

- 初期单文件传输上限为 128 MiB；超限返回明确错误。
- 下载只使用全新空 staging，校验后 no-replace 发布。任务恢复支持安全整文件重启，不表示文件内断点续传。
- 云 marker 证明当前授权可访问绑定命名空间，不代表公开接口返回了稳定账号 ID 或完整授权 scope。
- 搜索是不完备候选集；父目录过滤的实测失败仍保留。已知父目录的 fresh stat 不能当作全盘对象定位。
- 本地串行化、fresh 预检与写后核对不提供跨客户端条件写入或原子批处理保证。
- MCP、archive_replace、download_resume_verified 保持 false。其他操作系统未实测。
- 独立 CLI 集成的官方支持约定仍未知，详见 [COMPATIBILITY.md](../COMPATIBILITY.md)。

## 128 MiB 上限调整

按用户要求将包装层的单文件保护上限从 64 MiB 调整到 128 MiB，上传、下载、目录 manifest、任务恢复和内容回读全部显式使用新值。marker、恢复元数据和 Artifact 的独立读取上限未放宽。边界回归覆盖 64 MiB+1、128 MiB 进入传输读取，以及 128 MiB+1 在上游传输派发前拒绝；本地测试总数现为 156。此次没有新增真实 128 MiB 云端往返，不将本地阈值调整记作上游容量实测。

## 有界 tree

2026-10-13：交付 `tree --ref JSON`，默认深度 2、遍历目录预算 100、显示后代条目预算 1000，支持默认 JSON 及显式文本格式。起点为第 0 层，深度上限 32，目录和条目预算上限分别为 1000 与 10000。共用 Catalog 执行广度优先遍历，复用完整目录快照，在一次作用域核验内完成读取；不重复展开已观察到的目录身份。

`complete_for_depth` 表示请求深度内是否完整。预算或分支失败时保留已读结果，逐分支标记原因，以 `TREE_INCOMPLETE` 和非零退出码返回；到达指定深度属于正常完成。普通分支读取失败不影响其它分支，登录或作用域失效则停止。统计只覆盖显示的后代，未知尺寸单独计数。目录预算仅约束遍历枚举尝试，包含失败；作用域核验和起点定位所需读取不计入该预算。每个上游目录仍完整枚举，条目预算不限制单次请求读取量或严格耗时，多目录结果不提供原子快照保证。

主代理复跑 202 项测试通过，其中新增 10 项核心树行为测试和 12 项 CLI 测试；ResourceWarning 作为错误运行时无警告。ruff、mypy、compileall 和差异空白检查通过。独立审查确认非法引用在状态、缓存和 provider 初始化前拒绝，并校正文档中目录预算和路径定位读取的描述，最终 22 项 tree 测试独立复验通过。

构建 sdist/wheel 后，在独立安装环境和本机更新版本各验证 8 个真实子进程合成场景：105 文件目录完整读取、深度 0、目录预算、条目预算、文本控制字符转义、分支错误继续、登录失效停止、非法深度无上游调用。测试还确认只发生枚举和 marker 下载、不检查无关回收目录、绑定不变且不创建文件操作任务。上游由本地进程模拟，本轮未执行真实网盘 tree 验收。本机 CLI 和 skill 同步更新，保留原有配置入口。
