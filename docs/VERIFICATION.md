## 使用边界

- 初期单文件传输上限为 128 MiB；超限返回明确错误。
- 下载只使用全新空 staging，校验后 no-replace 发布。任务恢复支持安全整文件重启，不表示文件内断点续传。
- 云 marker 证明当前授权可访问绑定命名空间，不代表公开接口返回了稳定账号 ID 或完整授权 scope。
- 搜索是不完备候选集；父目录过滤的实测失败仍保留。已知父目录的 fresh stat 不能当作全盘对象定位。
- 本地串行化、fresh 预检与写后核对不提供跨客户端条件写入或原子批处理保证。
- MCP、archive_replace、download_resume_verified 保持 false。其他操作系统未实测。
- 独立 CLI 集成的官方支持约定仍未知，详见 [COMPATIBILITY.md](../COMPATIBILITY.md)。

## 128 MiB 上限调整

按用户要求将包装层的单文件保护上限从 64 MiB 调整到 128 MiB，上传、下载、目录 manifest、任务恢复和内容回读全部显式使用新值。marker、恢复元数据和 Artifact 的独立读取上限未放宽。边界回归覆盖 64 MiB+1、128 MiB 进入传输读取，以及 128 MiB+1 在上游传输派发前拒绝；本地测试总数现为 156。此次没有新增真实 128 MiB 云端往返，不将本地阈值调整记作上游容量实测。
